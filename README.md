# Portfolify

A modern online portfolio builder that helps users create, customize, and publish professional portfolios without needing advanced coding knowledge.

## Features

* User signup and login
* Secure password hashing
* Portfolio creation and editing
* Profile photo upload
* Resume upload
* Multiple portfolio templates
* Multiple color themes
* Font customization
* Profile photo styles
* Decorative styles
* Live portfolio preview
* Publish and unpublish portfolio
* Public portfolio URL
* PDF portfolio generation
* QR code generation
* GitHub and LinkedIn links
* Account management
* Responsive design

## Technology Stack

* HTML
* CSS
* JavaScript
* Python
* Flask
* SQLite
* ReportLab
* QRCode

## Installation

Install the required Python packages:

```bash
pip install -r requirements.txt
```

## Run the Application

```bash
python app.py
```

Then open the local address shown by Flask in your browser.
